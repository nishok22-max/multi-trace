# Dataset placement (manual)

TRACE makes no network calls and does not download data. Download the Microsoft Azure Predictive Maintenance dataset yourself and place these CSV files in this folder:

- `PdM_telemetry.csv`
- `PdM_errors.csv`
- `PdM_maint.csv`
- `PdM_failures.csv`
- `PdM_machines.csv`

These files are not committed (see `THIRD_PARTY_NOTICES.md`).
